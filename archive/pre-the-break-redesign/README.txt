ABHISHEK AGRAWAL — DESIGNER-MINDED DEVELOPER
===========================================

RUN LOCALLY
- Open index.html in a browser or use VS Code Live Server.
- The site uses plain HTML, CSS, and JavaScript; no build step is needed.
- GSAP and ScrollTrigger are included locally in assets.

PORTRAIT
- Place the original, cleaned photo at assets/abhishek-portrait.jpg.
- The hero loads this file and creates the scroll-controlled fragment scene from
  the same image. Without it, the site uses a typographic hero fallback and
  skips the portrait shatter.
- This file was not present in the repository during implementation.

PROJECTS
- GYANI-AI, Smart-FIR, and CallTrace Pro are retained from existing portfolio
  content. Earlier illustrative app screenshot mockups have been removed.
- The repository contains no project screenshots, verified public demos, or
  source repository URLs; no such links are invented.

MOTION AND RESPONSIVE DESIGN
- GSAP ScrollTrigger controls the pinned hero-to-About transition, reveals,
  and project-title movement. Mobile uses 12 fragments and a shorter pin;
  desktop uses 24 fragments.
- Reduced-motion settings disable scroll pinning and leave all content visible.
- Responsive breakpoints: 360px, 620px, 850px, and 1200px.
